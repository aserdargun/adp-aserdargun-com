# Cross-lab learning handoff

This application adopts lab-core 0.2.0 semantic contexts (wire version 0.1). The app-owned adapter lives in `src/ils/handoff.ts` (GEX: `src/ils/context.ts`) and is covered by `tests/handoff.test.ts`.

Canonical destinations and actual experiment routes come from `src/ils/learning-graph.json`, generated by ILS from the five app catalogs. Do not edit that snapshot or introduce hardcoded cross-lab URLs into adapters. In the sibling ILS checkout run `npx tsx tools/integration-graph.mjs --capture --sync`, then `node tools/integration-graph.mjs --check --check-consumers`. App formatters may normalize JSON whitespace.

Read the [complete integration contract](https://github.com/aserdargun/ils-aserdargun/blob/main/integrations/README.md) for payload fields, supported sizes, synthetic modeling assumptions, graph sources and receiver bounds. Only educational metadata may cross the boundary. Never send task text, documents, credentials, approvals, simulator traces or arbitrary application state.

Receiving apps validate before adapting. Incompatible contexts retain the ordinary experience. DCL requires an explicit training-to-inference conversion; its inference calculation does not use ADP training memory. TFL remains authoritative over synthetic request, KV and timing behavior. Return links restore the source experiment/concept, not exact simulation state. Existing legacy GEX/TFL pilot links are still supported.

Before release run this repository's existing validation/build commands and `tests/handoff.test.ts`, then browser-check the relevant chain in English desktop and Turkish mobile, including invalid context fallback and the return link.
